The first view is the **home view**.

### 3. Dania
The second view is the **product or information view**.  
In this section, users can see the available data in an organized way.

### 4. Guillermo
The third view is the **detail or interaction view**.  
Here, users can interact with the page and see more specific information.  
This view improves the experience because it allows a better connection between the user and the system.
